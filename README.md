# Professional Case Study

## SMD — Sistema de Medição de Desempenho

Minha aproximação com Dados surgiu da necessidade de resolver problemas reais relacionados a **mensuração, qualidade da informação e acompanhamento de desempenho operacional**.

Parte dessa experiência está relacionada à minha participação no **SMD — Sistema de Medição de Desempenho**, uma iniciativa desenvolvida em ambiente corporativo.

Entre os temas trabalhados estão:

- extração de dados via API;
- SQL Server e PostgreSQL;
- processos ETL;
- organização de dados em camadas;
- modelagem e padronização de informações;
- construção e validação de KPIs;
- comparação entre sistemas de origem e banco de dados;
- investigação de inconsistências;
- qualidade de dados;
- regras de negócio;
- governança da informação.

O SMD representa o **case de origem da minha evolução de Operações para Dados**.

Por se tratar de uma iniciativa corporativa, **código-fonte, dados, credenciais, regras internas e informações proprietárias não são disponibilizados publicamente**.

Um repositório independente será utilizado para documentar o case em nível conceitual, funcional e arquitetural, respeitando os limites de confidencialidade.
